ИНСТРУКЦИЯ: посадка лендинга «На обед в буфет» на naobedvbufet.ru
================================================================

Архив для загрузки:
/home/pasha/cook-and-fry/deploy/naobedvbufet.ru-upload.zip

Содержимое архива:
- index.html    — лендинг (главная страница), длинный стеклянный дизайн
- test.html     — тестовая копия лендинга для проверки на Android
- privacy.html  — политика конфиденциальности с реквизитами ИП
- robots.txt    — для поисковиков
- sitemap.xml   — карта сайта
- .htaccess     — красивые URL, сжатие, кеширование

Как работает форма
------------------
После заполнения формы на лендинге пользователь нажимает кнопку
«Получить расчёт». Сайт проверяет согласие, имя и телефон,
формирует текст заявки и показывает кнопку:
«Отправить заявку в Telegram».
При нажатии открывается чат с ботом @NaobedvbufetBot с уже
заполненным текстом заявки. Пользователю остаётся только нажать
«Отправить» в Telegram.

Согласие на обработку ПД (152-ФЗ):
- В форме стоит обязательный чекбокс с информированным текстом:
  конкретные ПД, цель обработки, ссылка на /privacy.
- Под формой дополнительный блок с подтверждением согласия.
- Политика конфиденциальности содержит полные реквизиты оператора.

Почему не через API:
- Сервер агента (82.26.94.231) недоступен из интернета по портам
  3001 и 8502, поэтому заявки нельзя принимать на рег.ру через
  PHP-прокси. Telegram-бот работает через публичное API Telegram.

ШАГ 1. DNS
----------
В личном кабинете рег.ру убедись, что:
- A-запись для @ (корень) → 37.140.192.183
- A-запись для www → 37.140.192.183
(или CNAME www → @)

ШАГ 2. Загрузка файлов
----------------------
1. Зайди в панель управления хостингом рег.ру.
2. Открой File Manager (или подключись по FTP).
3. Найди корневую папку сайта: обычно public_html, www или имя домена.
4. Удали из неё старые файлы сайта (или перенеси в папку old-backup).
5. Распакуй архив naobedvbufet.ru-upload.zip прямо в корневую папку.

После загрузки структура должна быть такой:
/
  index.html
  test.html
  privacy.html
  robots.txt
  sitemap.xml
  .htaccess

ШАГ 3. Проверка
---------------
Открой в браузере:
- https://naobedvbufet.ru/ — должен открыться лендинг
- https://naobedvbufet.ru/test.html — тестовая страница с Android-фиксами
- https://naobedvbufet.ru/privacy — политика конфиденциальности
- https://naobedvbufet.ru/robots.txt — текст robots.txt

Если /privacy выдаёт 404 — проверь, что .htaccess загрузился и работает mod_rewrite.

ШАГ 4. Проверка формы
---------------------
1. Заполни форму на главной (имя, телефон, компания/количество, согласие).
2. Нажми «Получить расчёт».
3. Под формой появится кнопка «Отправить заявку в Telegram».
4. Нажми — откроется Telegram с чатом @NaobedvbufetBot и готовым текстом.
5. Отправь сообщение в Telegram.
6. Убедись, что заявка дошла (chat ID 315724994).

Если @NaobedvbufetBot не написал после отправки — проверь, что бот запущен и у него есть доступ к чату 315724994.

ШАГ 5. SEO / 152-ФЗ
-------------------
- Политика конфиденциальности доступна по /privacy.
- Canonical на главной — https://naobedvbufet.ru/.
- Title/description уникальны.
- Для сдачи в РКН: заполни уведомление об обработке ПД, указав
  https://naobedvbufet.ru/ как полный URL сайта.

Android: почему добавлен test.html
----------------------------------
На Android мерцание часто вызвано:
- тяжёлыми blur-фонами (blob) на слабых GPU;
- синим всплеском при тапе (tap-highlight);
- резким скроллом при появлении клавиатуры;
- hover-анимациями, которые дергаются на тач-устройствах.

В test.html и index.html применены фиксы:
- на тач-устройствах блобы и hover-эффекты отключены;
- убран transition фона/текста у body;
- добавлен overscroll-behavior и tap-highlight-color: transparent;
- полям ввода задан font-size: 16px (убирает автоувеличение);
- при фокусе в поле страница плавно скроллит поле в центр экрана.

Проверяй сначала https://naobedvbufet.ru/test.html на Android.
Если мерцание пропало — фиксы работают, можно оставить index.html как есть.
